# 奇門遁甲與風水九宮方位工具

React + Vite 靜態網站，沿用 GitHub Pages 的 `/qi-men-dun-jia/` base path。

## 使用

- 原本奇門排盤：`/qi-men-dun-jia/` 或 `#/qimen`。
- 獨立風水工具：`/qi-men-dun-jia/#/feng-shui`。
- 輸入角度、拖曳滑桿或按八方快捷鍵，即時查看方向、後天八卦、洛書宮位與五行。
- 點選九宮只切換詳細資料，不改變輸入角度；實心標記代表量測方向，框線代表點選宮位。
- 可切換上北／上南，圖面旋轉不改變羅盤讀數。兩頁切換保留當次頁面狀態；重新整理回到預設值。

## 本機開發與驗證

```sh
npm ci
npm test
npm run build
npm run dev
```

Tailwind 以 PostCSS 編譯為本地 CSS，無須瀏覽器載入外部樣式 CDN。Node.js 20 以上。

## 方位規則

正北 0°，順時針增加，每個方向 45°。區間含起點、不含終點：22.5° 歸東北、337.5° 歸正北；360° = 0°。負角度與超過一圈的角度依 360° 正規化；空白或非有限數字不產生方位。滑桿步進 0.1°，輸入欄支援更細的讀數。

採後天八卦／洛書對照：坎一北水、艮八東北土、震三東木、巽四東南木、離九南火、坤二西南土、兌七西金、乾六西北金；中宮五土，無八卦及羅盤角度。參考：[《雲科漢學學刊》第24期](https://ghc.yuntech.edu.tw/images/Journal/Journal24.pdf)。

此版是方位對照，未包含八宅、玄空飛星、二十四山、吉凶、坐向判定、手機感測器或磁偏角校正。九宮格為示意圖，不是已完成平面圖定位。無 API、帳號或上傳功能，計算皆在瀏覽器完成。

## 模組邊界

- `src/App.jsx`：奇門排盤介面。
- `src/features/qimen/engine.js`：奇門純計算核心，供介面與回歸測試共用。
- `src/ToolApp.jsx`：hash 導覽與頁面狀態，不依賴伺服器路由 rewrite。
- `src/features/feng-shui/directions.js`：純資料與角度／版面函式，不引用奇門常數。
- `FengShuiPage.jsx`、`Compass.jsx`、`NinePalaceGrid.jsx`：獨立互動與呈現。
- 日後八宅、坐向、平面圖標註應分別新增模組，明確宣告流派與輸入，不共用奇門計算。

## 部署

推送 main 後，`.github/workflows/deploy.yml` 安裝鎖定依賴、執行單元測試及建置，成功後由原有 GitHub Pages 工作流程部署。瀏覽器驗收項目：0°／22.5°／337.5°／360°／-45°、清空、快捷方向、滑桿、宮位點選、上北／上南、跨頁狀態、原排盤與前後時辰按鈕。
